# Blessing Onyinye — Web Developer Starter Portfolio

A multi-page personal portfolio website built from scratch using HTML5, CSS3, and vanilla JavaScript to showcase web development, Python, and data analysis work.

## Pages Included
- `index.html` — Landing page introducing who I am and what I build
- `about.html` — Background, journey, and approach
- `projects.html` — Showcase of web/Python applications and data analysis projects with interactive category filtering
- `skills.html` — Technical skills and tools
- `contact.html` — Enquiry form with input validation, reset, and confirmation feedback

## Key Features
- **Consistent Multi-Page Navigation:** Shared navigation bar and footer across all five HTML pages.
- **Project Category Filter (`projects.html`):** Filter project cards by **All**, **Web & Python**, or **Data Analysis**, with active button highlighting.
- **Enquiry Form Handling (`contact.html`):** Prevents default page reload on submit, checks required fields (`full-name`, `email`, `message`), displays validation messages, resets inputs, and shows a confirmation pop-up.

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla DOM manipulation & event handling)
